# react-st-neots-chess

This repo contains source used to construct the web site for St Neots Chess Club,  a club based in Cambridgeshire, UK. The site was built using [React](https://react.dev), a library for JavaScript, and built using [Vite](https://vite.dev) to deploy the site to github-pages.
